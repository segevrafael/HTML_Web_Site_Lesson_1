# Taste of Levant - Middle Eastern Food Website

This responsive HTML/CSS/JS website is designed for Middle Eastern food enthusiasts, featuring authentic recipes, cooking courses, and more.

## Project Structure

- **HTML Pages**:
  - `index.html` - Homepage with hero banner and featured recipes
  - `recipes.html` - Recipe categories with filtering
  - `recipe-detail.html` - Detailed recipe pages
  - `courses.html` - Cooking course listings
  - `course-detail.html` - Detailed course information
  - `about.html` - About the company
  - `contact.html` - Contact form and FAQ
  - `login.html` - User login
  - `signup.html` - User registration

- **CSS**:
  - `css/styles.css` - Main stylesheet with responsive design

- **JavaScript**:
  - `js/scripts.js` - Functionality for mobile navigation, form validation, recipe filtering

- **Images**:
  - `images/recipes/` - Recipe images
  - `images/courses/` - Course images
  - `images/team/` - Team member photos
  - `images/auth/` - Authentication page images

## Features

- Responsive design for all screen sizes
- Recipe filtering by category
- Form validation
- Mobile-friendly navigation
- Interactive FAQ accordion
- Password visibility toggle
- Dynamic content loading

## Technologies Used

- HTML5
- CSS3 (Flexbox and Grid)
- JavaScript (ES6)
- Font Awesome icons

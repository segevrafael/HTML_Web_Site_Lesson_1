# Placeholder Images

These placeholder images are for development purposes only and should not be used in production.

## Naming Convention

Placeholders follow this format: `placeholder-[type]-[size].jpg`

### Types:
- food: Food and dish images
- chef: Chef and cooking personnel
- course: Cooking class and course imagery
- banner: Website banner images 
- profile: User profile images
- ingredients: Raw ingredient images

### Sizes:
- small: 400x300px
- medium: 800x600px
- large: 1200x800px

## Usage Example

```html
<img src="images/placeholders/placeholder-food-medium.jpg" alt="Delicious Middle Eastern dish" />
```

## File Format
All placeholder images use the JPEG format for consistency.

## Usage Guidelines
- **Hero sections:** Use large placeholders (1200x800px)
- **Recipe cards:** Use medium placeholders (800x600px)
- **Thumbnails:** Use small placeholders (400x300px)
- **Profile pictures:** Use the profile placeholders

Remember to replace all placeholders with actual optimized images before deployment.
